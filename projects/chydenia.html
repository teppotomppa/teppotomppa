SOFTWARE DEVELOPMENT

Chydenia
Mobile Application

A full-stack digital platform for Shopping Center Chydenia, combining a customer mobile app, an admin dashboard and a central API with persistent data storage.

Context Internships & bachelor's thesis
Team Two student developers
Client Shopping Center Chydenia

PROJECT STORY

From idea to outcome

Beginning. The project started as a digital service concept for Shopping Center Chydenia in Kokkola. During two professional internships, I worked with a fellow student and the Chydenia staff to understand the client’s needs and define a useful experience for visitors, stores and administrators.

Development. Together, we developed the platform from the ground up as part of our work and bachelor’s thesis. The customer-facing mobile app was built with React Native and Expo, allowing users to create accounts, browse stores and services, view opening hours, discover offers and events, send feedback and subscribe to newsletters. A React and Vite admin dashboard gave administrators and editors tools to manage this content, users and roles.

Outcome. The result was a connected full-stack pilot: a mobile app and admin dashboard communicating with a Node.js and Express REST API, with SQLite providing persistent storage for users, stores, opening hours, offers, events, feedback and newsletter subscriptions.

ADMIN DASHBOARD

Managing the mobile experience

A browser-based control panel for the people who manage Chydenia's content and services.

The Admin Dashboard was built for administrators and editors to control the content displayed in the Chydenia mobile app. Instead of changing the mobile application directly, authorized users can manage the shopping center's information from one browser-based interface.

The dashboard supports user roles and permissions, store and service management, opening hours, offers, events, newsletter subscriptions and customer feedback. Changes are stored through the backend and made available to the mobile app through the shared REST API.
