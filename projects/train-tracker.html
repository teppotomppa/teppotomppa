PROJECT STORY

From live data to a clear map

Beginning. This project was created as a pre-assignment for a job application. The goal was to build a simple and useful interface for exploring current train locations in Finland using publicly available real-time data.

Development. The application uses JavaScript and the Fetch API to retrieve GeoJSON data from Fintraffic's Digitraffic service. Leaflet and OpenStreetMap provide the interactive map, while train markers show each train's current position. Users can click a marker to view the train number, speed and last update time, or use the search control to locate a specific active train.

Outcome. The result is a responsive browser-based tracker that refreshes its data every 15 seconds. The application keeps the map current by updating moved trains, removing inactive markers and presenting the latest available information in a straightforward interface.

REAL-TIME DATA

Updated every 15 seconds

The app periodically fetches the latest train locations so the map reflects the current state of the network.

INTERACTION

Explore every marker

Clicking a train reveals useful details such as its number, speed and the time of its latest update.

SEARCH

Find a specific train

A train selector helps users locate an active train and focus the map on its current position.
