PROJECT STORY

From course brief to playable game

Beginning. The project started as the final assignment for an Advanced Web Development course. The goal was to create a complete web application, so I chose to build a retro-styled memory game with a visual identity inspired by classic game interfaces.

Development. The frontend was built with React, NES.css and custom CSS. Players can choose between Easy, Medium and Hard difficulty levels, while sound effects and animations make each round feel responsive. A Node.js and Express backend handles the API, and SQLite stores highscores persistently by difficulty.

Outcome. The result is a responsive full-stack game with a playable production deployment, a persistent highscore system and a clear separation between the React frontend and backend services. The API exposes endpoints for submitting scores and retrieving highscores for each difficulty level.

GAMEPLAY

Three ways to play

Easy, Medium and Hard modes change the challenge while keeping the core matching mechanic simple to understand.

PERSISTENCE

Scores that stay

Highscores are submitted through the backend and stored in SQLite, making the results available beyond a single session.

EXPERIENCE

Retro by design

NES.css, custom styling, sound effects and animations work together to give the game its playful arcade character.
